Part III. The General Assistant
===============================

The General Assistant answers questions about the dataset catalog, the portal,
and porous-media research methods. It routes each question to one of eight tools
and labels every answer with the source it came from.

The first chapter describes the assistant as a whole. The chapters after it each
cover one capability in depth.
