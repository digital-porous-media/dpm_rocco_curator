Part II. The Description Curator
================================

The Description Curator scores a dataset description against a ten-criterion
rubric, then rewrites it using evidence retrieved from papers you upload. Every
added statement carries a citation back to its source.

This part covers the web interface, the scoring rubric, the retrieval layer, and
the enhancement loop.
